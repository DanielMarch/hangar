# RECLASSIFIED in Phase 20.3, not closed. B27 wired the rest of internal/scopes
# — MergeScopes, NeedsReauthorization, NewSet, Set.Has and Set.Missing all have
# production callers now (the reauthorize scope merge, and the
# needs_reauthorization/missing_scopes fields on GET /api/v1/me/characters).
# HasAll is the BOOLEAN form of Missing, and production wants the list every
# time: a user is told WHICH scopes are missing, never merely that some are.
# Keeping both is not duplication to be resolved by deleting one — Missing is
# the answer and HasAll is the predicate the truth-table tests assert against,
# the same relationship rbac.Resolve has with ResolveAllLive. Adding a caller
# that computes the boolean twice, or throwing away the list to use the
# predicate, would be the allowlist wagging the codebase.
internal/scopes.Set.HasAll

# RECLASSIFIED in Phase 20.4. B25 wired the rest of the alerting stack — the
# Emitter, both fingerprint constructors, SemanticFields, the coalescing key,
# DeadLetterCount, render.Render, and catalogue.Thresholds/ThresholdSourceRoutes
# all have production callers now. The six below do not, and each is a
# MEASUREMENT rather than a mechanism:
#
# ValidateThresholds is §4.4's rule verbatim — "a threshold alert whose source
# route is not in the sync set is a BUILD-TIME error". A build-time check has no
# production caller by definition; `make check-alert-sources` is its caller, and
# giving it a second one inside cmd/hangar would not make the build safer, it
# would make a passing build depend on a process starting. Its runtime
# counterpart — "the route is in the sync set but THIS installation is not
# polling it" — is a different question and IS wired, in
# alerting.Evaluator.reportUnpollableThresholds.
#
# The four counters are Gate 4's parity arithmetic over a MEASURED baseline
# (docs/BASELINE.md §4: 54 alert types across 8 domains, 5 of them Skyhook).
# Nothing in a running installation needs to count its own catalogue; the tests
# that assert the count against the measurement are the whole point of the
# count existing.

internal/alerting/catalogue.ValidateThresholds
