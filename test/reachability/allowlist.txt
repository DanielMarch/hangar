# B22, B24, B30, B33 and B34 were ALL CLOSED IN PHASE 20.5 and their entries
# are gone rather than annotated — 26 symbols across five defects, plus the
# whole of internal/sde. This section is now down to one open group.
#
# GATE7 — PARTLY CLOSED IN PHASE 20.6. Six of the ten entries are gone:
#
#   * BreakingControllers, PendingControllers and UnshimmableControllers were
#     DELETED, not wired. They returned one representative path per
#     controller, which cannot describe CharacterController now that it spans
#     a served route and pending routes with three different reasons.
#     v2shim.Classification() replaces them per-ROUTE and Register() reads it,
#     so the router no longer hard-codes anything.
#   * ItemEnvelope, Float and FloatValue became reachable: corporation.sheet
#     is the shim's first single-resource route (ItemEnvelope, and tax_rate
#     through Float), and contacts' NOT NULL standing now states itself with
#     FloatValue instead of a bare Num.
#
# The four below are the money path, and they are NOT "waiting for the routes
# that would use it" — that reason was wrong twice over, and both corrections
# were made by writing the route and running it:
#
#  1. They took pgtype.Numeric. sqlc.yaml overrides every numeric column to
#     shopspring/decimal (Principle 9), so no store row has ever produced a
#     pgtype.Numeric and these were UNCALLABLE, not merely uncalled. Fixed in
#     20.6 — they now take decimal.Decimal / decimal.NullDecimal.
#  2. The one route that would exercise them, character.wallet-journal, was
#     written and then RECLASSIFIED as pending on measurement: the corpus
#     records "amount": 9007199254741000, and 9007199254740993.01 parses to
#     the different float64 9007199254740994. Legacy's loss is MySQL's/PHP's
#     14-significant-digit rounding, not IEEE-754 nearest, so Money's
#     round-trip cannot reproduce those bytes. See reasonMySQLDoubleRounding
#     in internal/api/v2shim/classification.go.
#
# Closing these needs the PHP recorder re-run with serialize_precision
# measured — not more Go.

# RECLASSIFIED in Phase 20.3, not closed. B27 wired the rest of internal/scopes
# — MergeScopes, NeedsReauthorization, NewSet, Set.Has and Set.Missing all have
# production callers now (the reauthorize scope merge, and the
# needs_reauthorization/missing_scopes fields on GET /api/v1/me/characters).
# HasAll is the BOOLEAN form of Missing, and production wants the list every
# time: a user is told WHICH scopes are missing, never merely that some are.
# Keeping both is not duplication to be resolved by deleting one — Missing is
# the answer and HasAll is the predicate the truth-table tests assert against,
# the same relationship rbac.Resolve has with ResolveAllLive. Adding a caller
# that computes the boolean twice, or throwing away the list to use the
# predicate, would be the allowlist wagging the codebase.
internal/scopes.Set.HasAll
